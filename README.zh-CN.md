# 废弃塑料制水 0.7.1

既然塑料是由碳、氢、氧等元素组成的，那么理论上，我们也能从塑料中获得水，对吧？

本模组在原版化学系统的基础上，新增了烧杯、蒸馏器、药匙及多种化学试剂，让玩家能够尝试将废弃塑料转化为水。

从加热处理、蒸馏回收，到过滤、盐析和萃取，玩家可以体验一套完整的化学加工流程，也可以结合原版净水机制，探索其他处理方法。

至于花费这么多资源，只为了得到一点水是否值得……至少在化学上，这件事很有意思。

基础价格：加热蒸馏装置200，250mL烧杯35，药匙7，己烷溶液瓶5，食盐瓶5。已有物品读档同步基础价格；实际成交价仍受原版议价、状态和内容物影响。

## 语言

简体中文、繁体中文环境使用已有中文文案；所有其他语言（包括英文、日文、法文等）使用英文。英文显示名为 Water from Waste Plastic。物品、药匙描述、机器按钮与提示、扫描报告、试纸、传闻和纸条均已适配。切换游戏语言后重新载入存档，以刷新已有物品和机器界面。己烷描述仍为空。模组列表简介始终同时提供中文与英文。

## 游戏过程

- 下层区化学家（普通、稀有与以物易物）来访首次主对话有25%概率先说一句塑料制水传闻，再继续原对话与交易。公民的新增传闻已移除。
- 下层区声望达到20并已解锁退休化学家时，记录当前日期；下一游戏日或之后首次开店送一张文档纸条，使用原版手写便签贴图（items_misc/handnote），打开时也直接使用原版手写便签界面。优先前柜台，其次后备库存、主库存、文档夹；全满时保留待送。已送达状态保存在当前存档中，读档不重复发放。旧存档已经满足条件时，从首次检测当天起安排次日送达。
- 当前苯生成量每批随机为塑料体积的7.00%～8.00%，步进0.01个百分点，按整数微升取整。5mL塑料产生0.35～0.4mL苯，总产液4.95～5mL；其余成分生成量保持原有值。

## 获取方式

- 250mL烧杯仍为日用品；烧杯、药匙和加热蒸馏装置仅由退休化学家在展示机器的售货对话中带来：烧杯100%、蒸馏器50%，药匙仍每次携带。三者先于原版设备摆放，优先占用柜台空间；不加入普通收货或随机掉落池。
- 每拆开一份原版「化学用品（普通）」，保留原来的两瓶酒精、脂结合剂、酸、碱，额外获得己烷溶液一瓶、10mL食盐一瓶。取消原版拆包确认不会获得物品。「化学用品（管制）」不额外添加。
- 选择化学家开局，初始装备额外获得烧杯、药匙各一件。
- 购买王尔德的化学家装备服务（原版 RETIRED_CHEMIST，会给予设备并介绍退休化学家），后备库存额外获得烧杯、药匙各一件。普通 CHEMIST 电话介绍服务不发装备。
- 获得装备只发生在新开局或购买服务时；读档不重复发放，已完成的历史事件不追溯补发。空间不足沿用原版安置／溢出规则，购买或拆包前留出空间。

空己烷瓶和食盐瓶可盛装液体或固体食盐，烧杯中的干盐可以整份倒回瓶中；药匙仍只能取放固体。小瓶酒精、脂合剂、酸、碱和新增己烷／食盐瓶，完全倒空后拖入无液体的烧杯均产1mL塑料。容器有任何液体或固体时不会被回收。己烷物品描述已清空。

## 操作

- 原版空瓶或空水桶拖入无液体的250mL烧杯。标准／大号／微型／小号瓶产5／8／1／3mL塑料，空水桶产20mL。加热板实际温度超过70°C持续3个游戏秒后软化。
- 加热蒸馏装置占4×3，只有两个烧杯槽和「1 加热」「2 蒸馏」。加热把软化塑料转为含原版污染物和苯的冷凝液。
- 每瓶新己烷溶液总量50mL，其中化学污染物与重金属总计随机占5%～8%，二者分配也随机且均大于0；实际己烷46～47.5mL。旧瓶／旧存档保持已有成分，不重新随机。滴管会按原版规则连同杂质一起取样。
- 盐瓶直倒会转移全部食盐，空间不足时倒至装满、余量留瓶；药匙每次最多取放1mL固体；含水烧杯里的盐并入原版矿物质，并记录实际加盐来源。
- 蒸馏一次收集全部水、原化学污染物含量的30%及未去除的苯，清空输入杯；其余普通杂质、盐、己烷和已去除的苯直接消失。
- 去苯需要实际己烷量大于等于苯量；临时效率为无盐75%、加入至少1mL盐后100%。自然矿物质不能代替实际加盐。
- 成分光谱仪可扫描塑料和各类成分。水质扫描仪和未使用的水质试纸只能检测实际含水的容器；空杯、只有塑料、盐或己烷时拒绝。试纸沿用原版显色、纯度记录和一次性用后状态。
- 水质扫描仪及试纸报告中的实测／标注水质、单位和操作按钮按模组语言显示中文或英文。拖拽图标直接跟随鼠标，并减少未变化时的重复状态更新。

## 配置及验证

安装目录下 distillation-settings.json 可调 unsaltedRemovalPercent、saltedRemovalPercent，满足 0 ≤ 无盐效率 < 加盐效率 ≤ 100，重启生效。更新保留现有配置。

构建、规则断言、补丁入口及字段绑定检查、模组扫描记录见 VALIDATION.txt。此前中文版本已有用户游戏内测试反馈；本候选版的英文界面排版尚未游戏内复测。发布版与开发版须分别核对，不把历史运行记录当作本版验收。

发布版不含刷物品、自测入口或自动自测代码。开发者可用 build.ps1 -DeveloperTools 构建带测试工具的开发版；请勿上传开发版。获取方式需要在留有空间的测试存档中检查，具体步骤见 CHANGES-0.7.1.md。

## 构建及安装

build.ps1 引用本地游戏程序集构建、运行规则测试并生成 package/ChemistryPrototype。首次安装使用 install.ps1；更新前关闭游戏并备份旧目录，覆盖DLL与manifest.xml，保留自定义配置及原贴图。

卸载前取出槽内物品、移除模组物品并保留存档备份。温度、体积、杂质及处理率均为游戏抽象。



## 固体成分扩展

食盐定义具有 solid=true。SolidComponentDefinition 与 ModEntry.RegisterSolidComponent 是本模组公开的扩展入口（不是虚构的原版API）：其他模组可注册独立的成分标识、中文名称和微升容积标签，并通过原版 ModifyTag 写入烧杯。注册固体会计入容积、成分表和干固体贴图判断；转移、溶解和反应仍需为新成分另行实现。纯固体粉末使用 beaker_solid，含液体时使用液位图，塑料保留专用贴图。
